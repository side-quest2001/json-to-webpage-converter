# JSON to Candidate Webpage Converter

A React + TypeScript + Vite app that converts candidate JSON into a clean single-window webpage view.

## Features

- Paste or edit JSON directly.
- Instant JSON validation.
- Opens a separate tab with all candidates in one continuous window (no pagination).
- Candidate cards with detailed fields and clean visual layout.
- Built-in search by name, role, and company.
- Custom report title.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
